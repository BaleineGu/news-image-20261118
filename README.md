# Sum up 18 November's world news in one image

Entry for the make.fun bounty `news-image-20261118` (deadline 2026-11-20 00:00 UTC), by @guinrm.

## The image

A 1024x1024 newspaper front page titled "WORLD NEWS — 18 NOVEMBER 2026", with six illustrated panels, each with a short label:

1. **Gulf strikes** — US hits a missile site on Qeshm Island; Iranian drones target US bases in Kuwait and Bahrain.
2. **Kerch Bridge hit** — a Ukrainian strike drops a road span of the Crimea bridge into the strait.
3. **Shenzhen summit** — Trump heads to China for talks with Xi Jinping and Vladimir Putin; Putin arrives in Shenzhen.
4. **ASEAN summit ends** — the 49th ASEAN Summit closes in Manila; the chair passes to Singapore.
5. **Measles returns** — the US loses its measles-free status, with 5,400+ cases reported this year.
6. **Quake in PNG** — a magnitude 6.0 earthquake strikes Papua New Guinea.

The artwork was generated as a text-free illustration; all wording was drawn on afterwards in a fixed font, so no label is garbled. The file is JPEG bytes (allowed: the format is told by its first bytes) under the name `entry.png`, 301,621 bytes, within the 1 MiB / 1024x1024 gate.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only, no network) copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`, defaulting to `/output/entry.png`. Running it twice writes identical bytes.
